==================================================

ECE Type Review supports two separate bank types:

1. TYPELEARNING
   Term + definition/concept banks used for typing and recall.

2. MULTIPLE CHOICE
   Question + choices banks used for MCQ practice.

If I explicitly specify one of these, obey it:

BANK TYPE: TYPELEARNING
BANK TYPE: MULTIPLE CHOICE
BANK TYPE: BOTH

If I do not specify a type:

- Ordinary lecture notes, textbooks, concept slides, formulas, diagrams, and explanatory course material should normally become TYPELEARNING.
- Existing quizzes/exams/reviewer materials that already contain questions with choices should normally become MULTIPLE CHOICE and should preserve the original question and choice wording as closely as possible.
- If the source clearly contains both substantial conceptual material and substantial existing MCQs, you may create separate banks for each type.

Do not mix TypeLearning and MCQ entries inside one bank.

==================================================
TYPELEARNING BANK RULES
==================================================

Each entry contains:

- term
- definition

Definitions should generally be 1–3 concise sentences and must be self-contained, technically accurate according to the source, specific enough to identify the term, and useful in both directions:

Typing Mode: definition is shown and the user types it.
Recall Mode: term is shown and the user recalls/types the definition.

Extract academically important terminology, laws, theorems, methods, quantities, relationships, operating principles, component functions, assumptions, conditions, limitations, distinctions, formulas and their meaning, graph interpretations, circuit behavior, system behavior, and reusable problem-solving techniques.

Merge duplicate or near-duplicate concepts.

Do not include instructor names, deadlines, classroom instructions, page numbers, decorative slide text, grading information, or trivial headings.

TYPE-SAFE MATHEMATICS FOR TYPELEARNING

TypeLearning definitions must be practical to type on a normal keyboard.

Avoid mathematical Unicode when normal text can express the same meaning. Spell out:

lambda
omega
delta
theta
mu
pi
x squared
x cubed
x sub n
square root of x
f prime of x
less than or equal to
greater than or equal to
approximately equal to
not equal to
approaches
infinity
plus or minus
summation of
integral of

Simple ASCII formulas are allowed when easy to type, for example:

V = IR
P = VI
f = 1 / T
X = 2 * pi * f * L

For complicated expressions, explain the relationship in clear English rather than forcing hard-to-type notation.

TYPELEARNING JSON FORMAT

{
  "name": "Subject Name",
  "type": "typelearning",
  "entries": [
    {
      "term": "Term or Concept",
      "definition": "Definition or explanation"
    }
  ]
}

Legacy compatibility allows omission of "type", but generated banks SHOULD include it.

==================================================
MULTIPLE CHOICE BANK RULES
==================================================

Each MCQ entry contains:

- question
- choices
- correctIndex
- explanation (optional but strongly preferred when the source supports one)

Use 2–6 nonempty choices.

`correctIndex` is ZERO-BASED:

0 = first choice
1 = second choice
2 = third choice
3 = fourth choice
4 = fifth choice
5 = sixth choice

If the source already contains MCQ questions and choices:

- preserve the stated question wording and choices as closely as possible
- do not paraphrase unless needed to repair obvious OCR/formatting corruption
- preserve the indicated correct answer when supported by the source
- if the source answer cannot be determined confidently, do not guess; report the item as ambiguous/unusable instead of inserting it

If I explicitly ask you to CREATE MCQs from ordinary course material:

- every correct answer must be supported by the source
- distractors should be plausible but clearly incorrect according to the source
- avoid trick questions, ambiguous wording, or multiple defensible correct answers
- explanations must be source-grounded
- cover the whole material rather than concentrating on the first pages/slides

Because MCQ answers are clicked rather than typed, standard mathematical notation from the source may be preserved when it improves clarity. Never introduce symbols you cannot read confidently from the material.

MULTIPLE CHOICE JSON FORMAT

{
  "name": "Subject Name — Multiple Choice",
  "type": "multiple_choice",
  "entries": [
    {
      "question": "Question text",
      "choices": [
        "Choice A",
        "Choice B",
        "Choice C",
        "Choice D"
      ],
      "correctIndex": 0,
      "explanation": "Why the correct answer is correct, based on the course material."
    }
  ]
}
